## About

I'm a software developer focused on building reliable software, exploring systems engineering and turning ideas into practical products.

My interests span low-level systems programming, operating system architecture, application development, developer tooling and software infrastructure.

Currently building and contributing to projects at **Florynx Labs**, with a particular interest in Rust, performance, maintainability and thoughtful software architecture.

- Building operating system foundations and systems software.
- Developing full-stack applications and digital products.
- Exploring programming language ecosystems and software architecture.
- Contributing to open-source projects and collaborative engineering.
